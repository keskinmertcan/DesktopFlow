# Changelog

## 1.0.0

First release of DesktopFlow for Windows 11 x64.

- Organize the desktop and Downloads with separate folder maps and separate monitoring switches.
- Preview a move before it happens, then move files without deleting or overwriting them.
- Watch new files in the background, wait until a download finishes writing, and skip folders, shortcuts, hidden files, and system files.
- Add, edit, disable, reorder, and delete automation rules. Overlapping rules are listed.
- Keep activity history in a local SQLite database and undo moves, including after the app restarts.
- Close the window to the notification area, or exit completely from the tray menu.
- Optional Windows startup, English and Turkish interface text, and a first-run setup that does not move files until you confirm.
